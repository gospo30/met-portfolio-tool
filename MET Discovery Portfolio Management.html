    Data Architecture & Governance

    Every opportunity carries the full data model below. The set is fully extensible — add fields in the data layer as your process matures.

    Data Model per Opportunity

    • Need statement, evidence, stakeholder impact
    • Pain score, population affected, economic & clinical impact
    • Competitive intensity, regulatory complexity, technical feasibility
    • Required capabilities (captured via solution + assumptions fields)
    • Strategic alignment, Stryker advantage, time to value
    • Investment Estimate ($, derives the Investment Required score and TAM ÷ Investment ROI), risk, confidence level
    • Roadmap planning: Product Segment, Project Start Year, Development Duration (months)
    • Unknowns, assumptions, portfolio category, horizon, offensive/defensive posture

      Team Sync Setup (SharePoint)

      Connects this browser to your team's shared SharePoint list via three Power Automate flow URLs. Once connected, changes save automatically and sync across everyone who has this set up — no more Export/Import JSON. These URLs act like a password to your portfolio data: paste them here (stored only in this browser, never in the file itself) and share them with your team out-of-band (e.g. Teams chat), not by posting them anywhere public.

      Build Weights (AHP)

      The Analytic Hierarchy Process (AHP) turns a series of head-to-head judgments into defensible, numeric composite weights, with a built-in check for contradictory answers (the Consistency Ratio below). For each pair, say which of the two lenses matters more when deciding which MET discovery opportunities to prioritize, and by how much — leave the slider centered if they matter equally. This only sets the 8 composite weights; it doesn't touch the Risk Penalty slider. Best done as a group exercise with whoever owns these tradeoffs (R&D, Finance, Marketing), not solo.
